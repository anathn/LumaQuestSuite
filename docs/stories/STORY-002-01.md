## Overview

Create the two foundational tenancy tables — `Family` and `ChildProfile` — that every other domain table in the system will ultimately reference (Architecture §4.2).

## User Story

As a developer, I want `Family` and `ChildProfile` SQLAlchemy models with a corresponding Alembic migration, so that every later story has the tenancy tables to foreign-key against.

## Acceptance Criteria

### Functional Requirements

- [ ] `Family` model: `id` (UUID PK), `owner_user_id`, `timezone`, `created_at`.
- [ ] `ChildProfile` model: `id` (UUID PK), `family_id` (FK → `Family.id`, indexed, not null), `display_name`, `grade_band`, `preferences` (JSON), `created_at`.
- [ ] No legal/full names or public identifiers stored on `ChildProfile` beyond a parent-chosen `display_name` (Architecture §5.4 COPPA-aware posture).
- [ ] Alembic migration creates both tables with the `family_id` foreign key and an index on `ChildProfile.family_id`.
- [ ] Migration is additive-only (new tables, no destructive changes) per Architecture §4.4.

### Non-Functional Requirements

- [ ] Performance: `family_id` is indexed on `ChildProfile` since every reading/spelling query will filter by it.
- [ ] Accessibility: N/A (data model story).
- [ ] Error handling: attempting to create a `ChildProfile` with a non-existent `family_id` fails at the database constraint level.

### Code Structure Suggestions

```python
# apps/api/app/accounts/models.py
import uuid
from datetime import datetime
from sqlalchemy import ForeignKey, String, JSON
from sqlalchemy.orm import Mapped, mapped_column, relationship
from app.db import Base

class Family(Base):
    __tablename__ = "families"

    id: Mapped[uuid.UUID] = mapped_column(primary_key=True, default=uuid.uuid4)
    owner_user_id: Mapped[uuid.UUID]
    timezone: Mapped[str] = mapped_column(String(64))
    created_at: Mapped[datetime]

class ChildProfile(Base):
    __tablename__ = "child_profiles"

    id: Mapped[uuid.UUID] = mapped_column(primary_key=True, default=uuid.uuid4)
    family_id: Mapped[uuid.UUID] = mapped_column(ForeignKey("families.id"), index=True, nullable=False)
    display_name: Mapped[str] = mapped_column(String(80))
    grade_band: Mapped[str] = mapped_column(String(32))
    preferences: Mapped[dict] = mapped_column(JSON, default=dict)
    created_at: Mapped[datetime]
```
